## Before publishing
Open `index.html` and replace:
- `https://www.linkedin.com/` with your actual LinkedIn profile
- `https://github.com/` with your actual GitHub profile
- `YOUR_EMAIL@example.com` with your email address

## GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, and the entire `assets` folder.
3. Go to Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide your live website URL.
